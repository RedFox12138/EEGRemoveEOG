作为你的博士导师，我很高兴来指导你这个课题。你选择的这个点——**单通道、高效、轻量级**的深度学习去伪影网络——非常具有挑战性和实用价值。

在多通道EEG中，我们可以利用空间信息（如ICA或回归方法）来分离EOG。但在单通道上，网络必须学会**仅从信号的形态（morphology）**上区分脑电（高频、节律性）和眼电（低频、高幅、特定冲击形态）。

你对“高效”和“轻量”的追求是正确的，这决定了模型是否能用于可穿戴设备或实时处理。我们不能简单地堆叠Transformer或大型U-Net。

我为你设计一个创新的网络结构，我称之为 **“轻量级门控残差自编码器” (Lightweight Gated Residual Autoencoder - LGRAE)**。

------



### 1. 核心创新理念：学习“伪影”而非“信号”



许多去噪网络的思路是“端到端”学习，即 $Input \rightarrow \text{BlackBox} \rightarrow Output$。这种方式参数利用率不高，且难以解释。

我们的核心理念是**显式地分离任务**：

1. **网络不直接学习“干净的EEG”。**
2. **网络学习预测“EOG伪影本身”。**
3. **网络学习一个“门控”来决定在何时何处进行减法操作。**

最终的输出是：



$$\hat{x}_{clean} = x_{noisy} - (\hat{A} \odot \hat{x}_{eog})$$

其中：

- $x_{noisy}$ 是带噪的输入信号。
- $\hat{x}_{eog}$ 是网络预测的EOG伪影分量。
- $\hat{A}$ 是网络学习到的**时间注意力门控 (Temporal Attention Gate)**，其值在0到1之间，表示“此处有多大把握是伪影”。
- $\odot$ 是哈达玛积（逐元素相乘）。

这种结构的好处是：

- **可解释性强：** 我们可以可视化 $\hat{x}_{eog}$（看看网络学到的伪影长什么样）和 $\hat{A}$（看看网络在哪里找到了伪影）。这对毕业设计论文至关重要。
- **保护真实信号：** 通过门控 $\hat{A}$，网络只在它“确信”有伪影的地方进行减法，避免了在干净信号段“过度去噪”或引入失真。
- **任务解耦：** 网络被“逼迫”去学习伪影的形态学特征（通过 $\hat{x}_{eog}$ 分支）和伪影的定位（通过 $\hat{A}$ 分支）。

------



### 2. LGRAE 网络结构详解



为了实现“轻量级”和“高效”，我们将大量使用 **1D深度可分离卷积 (1D Depthwise Separable Convolutions)**，这是实现参数和计算量大幅降低的关键技术。

整个网络是一个双解码器（Dual-Decoder）结构：

```
Input: x_noisy (Batch, 1, TimeSteps)
   │
   ▼
┌──────────────────┐
│  共享编码器 (Encoder)  │  (使用 1D 深度可分离卷积 + 下采样)
└──────────────────┘
   │
   ▼
  z (特征表示)
   ├──────────────────┐
   │                  │
   ▼                  ▼
┌──────────────┐   ┌───────────────┐
│ 解码器 A (伪影)   │   解码器 B (门控)    │ (轻量级)
└──────────────┘   └───────────────┘
   │ (上采样 + 1D DSC)  │ (上采样 + 1D DSC)
   ▼                  ▼
  x_eog_hat           A_hat (Sigmoid激活)
   │                  │
   └───────( ⊙ )───────┘  (Hadamard 积)
               │
               ▼
           x_artifact_gated
               │
   ┌───────────( - )───────────┐ (残差连接)
   │                           │
x_noisy                      ▼
   │                     x_clean_hat (最终输出)
   │                         │
   └───────────(Loss)────────┘
                  │
                x_true_clean (Ground Truth)
```



#### 2.1 共享编码器 (Encoder)



这是特征提取的主干，目标是用最少的参数捕捉信号的形态特征。

- **结构：** 3-4 层的 1D 深度可分离卷积 (DSC) 栈。
- **DSC 块：** `(1D Depthwise Conv -> LayerNorm -> PReLU/GeLU -> 1D Pointwise Conv)`。
- **下采样：** 使用 `AvgPool1D` 或步长为2的DSC，将时间维度逐步压缩（例如 $T \rightarrow T/2 \rightarrow T/4 \rightarrow T/8$）。这有助于网络感知不同时间尺度的特征。



#### 2.2 解码器 A (伪影重构分支)



- **目标：** 从压缩的特征 $z$ 中重构出EOG伪影的波形 $\hat{x}_{eog}$。
- **结构：** 与编码器对称。
- **上采样：** 使用 `nn.Upsample` (mode='linear') 或 1D转置卷积 (Transposed Conv)。`Upsample` 更轻量且不易产生棋盘效应。
- **块：** 同样使用DSC块。
- **输出层：** 一个 `Conv1D(kernel_size=1)` 将通道数映射回1，激活函数为 `tanh` 或线性（因为伪影可以有正有负）。



#### 2.3 解码器 B (时间注意力门控分支)



- **目标：** 从压缩的特征 $z$ 中生成时间注意力图 $\hat{A}$。
- **结构：** 这是一个**非常轻量**的解码器，可以比解码器A浅。
- **块：** 同样使用上采样 + DSC。
- **输出层：** 一个 `Conv1D(kernel_size=1)` 映射回1个通道，**激活函数必须是 `Sigmoid`**，将输出 $\hat{A}$ 限制在 `[0, 1]` 区间。

------



### 3. 如何实现“高效”与“轻量”



1. **深度可分离卷积 (DSC)：** 这是关键。一个标准 1D 卷积（$C_{in}$ 通道, $C_{out}$ 通道, 核 $K$）的参数量是 $K \times C_{in} \times C_{out}$。一个DSC的参数量是 $(K \times C_{in}) + (1 \times C_{in} \times C_{out})$。当 $C_{in}$ 和 $C_{out}$ 较大时（例如32, 64），参数量可减少一个数量级。
2. **通道数量：** 保持编码器和解码器中的通道数较小（例如 16, 32, 64）。
3. **激活函数：** 使用 `PReLU` 或 `GeLU`。`PReLU` 几乎不增加参数，但适应性比ReLU强。
4. **归一化：** 使用 `LayerNorm` 或 `GroupNorm`。对于时间序列，它们通常比 `BatchNorm` 更稳定，尤其是在batch size较小的时候。

### 4. 毕业设计实施指南



作为你的导师，我还需要给你一些关于如何完成这个项目的指导：



#### 4.1 数据集构建 (关键)



单通道去噪，**你需要成对的 (Noisy, Clean) 数据**。

- **最佳方案（半合成）：**

  1. 从多通道EEG数据（如 PhysioNet 上的数据库）中，使用 ICA 或其他BSS（盲源分离）方法，分离出“相对干净的EEG”分量和“纯EOG”分量。
  2. 找到 EEG 中没有伪影的片段，作为你的 $x_{true\_clean}$。
  3. 将“纯EOG”分量（或你单独采集的眨眼、眼动数据）以不同的信噪比（SNR）随机叠加到 $x_{true\_clean}$ 上，生成 $x_{noisy}$。

- **次选方案（真实数据）：**

  1. 使用多通道数据，运行 ICA 得到干净的信号 $x_{clean}$。
  2. 从 *原始* 数据中任选一个通道作为 $x_{noisy}$。
  3. 使用 $x_{clean}$ 中对应的通道作为 $x_{true\_clean}$。

  - *注意：这个方案的 $x_{true\_clean}$ 并不完美，但可以接受。*



#### 4.2 损失函数 (Loss Function)



你需要一个在时域和频域上都表现良好的损失。

1. **主要损失 (时域)：** $\hat{x}_{clean}$ 和 $x_{true\_clean}$ 之间的损失。
   - **推荐使用 `Smooth L1 Loss`** (Huber Loss)。它对离群点（如伪影残留）不如 $L_2$ (MSE) 敏感，同时在接近0时比 $L_1$ (MAE) 更平滑。
   - $L_{main} = \text{SmoothL1Loss}(\hat{x}_{clean}, x_{true\_clean})$
2. **辅助损失 (可选，但推荐)：**
   - **门控稀疏损失 (Gate Sparsity Loss)：** 我们希望门控 $\hat{A}$ 只在有伪影时才激活。
     - $L_{gate} = \lambda_1 \cdot ||\hat{A}||_1$ (L1 范数，鼓励稀疏)
   - **伪影重建损失：** 如果你的数据集能提供 $x_{eog\_true}$ (即你添加的伪影)，你可以增加一个监督损失。
     - $L_{artifact} = \lambda_2 \cdot \text{SmoothL1Loss}(\hat{x}_{eog}, x_{eog\_true})$

**总损失：** $L_{total} = L_{main} + L_{gate}$ (或 $+ L_{artifact}$)。



#### 4.3 对照实验 (Baselines)



你的论文需要证明你的LGRAE模型是优越的。你必须设置对照组：

1. **经典方法：** 带通滤波 (例如 0.5-40 Hz)。
2. **简单DL：** 一个简单的 1D CNN 自编码器 (AE)。
3. **标准DL：** 一个 1D U-Net。
4. **(可选) 你的创新点A：** 标准 1D U-Net，但所有卷积替换为深度可分离卷积（我称之为 **Mobile-UNet-1D**）。这本身也是一个很好的轻量级模型。
5. **你的创新点B：** 你最终的 LGRAE 模型。



#### 4.4 评价指标 (Metrics)



- **时域：**
  - RMSE (均方根误差)
  - SNR 改善 (Signal-to-Noise Ratio improvement)
- **频域 (非常重要)：**
  - **功率谱密度 (PSD) 对比：** 绘制 $x_{noisy}$, $x_{clean}$ 和 $\hat{x}_{clean}$ 的PSD图。你必须证明：
    1. EOG 的低频功率 (如 < 2 Hz) 被显著抑制。
    2. EEG 的关键频段 (如 Alpha: 8-13 Hz, Beta: 13-30 Hz) 的功率**未被破坏**。
- **模型性能：**
  - 参数量 (Params)
  - FLOPS (每秒浮点运算次数)
  - Inference Time (推理时间)
